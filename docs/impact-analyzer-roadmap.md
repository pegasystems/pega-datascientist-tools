# Impact Analyzer roadmap

Open follow-ups for Impact Analyzer. P2 is medium priority; P3 is exploratory.

## Features and UI

- **P2 — Drill down by offer:** Extend the channel breakdown to Issue, Group,
  and Action where supported by the data. Consider cannibalization guidance
  for group/action-level negative lift.
- **P2 — Channel in experiment cards:** Show the selected channel consistently
  in the experiment cards as well as the chart and summary table.
- **P3 — Interaction History:** Implement and test `from_ih()` with the
  required column mapping and validation.

## Sample data

- **P3 — Fresh demo dates:** Consider shifting bundled sample dates to today
  on load, without changing user-supplied data.
